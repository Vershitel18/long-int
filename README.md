# Long Int

## Задание

В данном задании вам предлагается реализовать на ассемблере библиотеку для работы с длинной арифметикой.
Эта библиотека должна поддерживать сложение, вычитание и умножение больших чисел одинакового размера, а также их ввод и вывод.

Некоторая часть, общая для всей арифметики, а также функции, отвечающие за работу с вводом-выводом, уже реализованы в [common.asm](lib/common.asm) и [io.asm](lib/io.asm) соответственно.
Вам же необходимо реализовать функции `long_int_add`, `long_int_sub` и `long_int_mul`.

## ABI

В этом задании предполагается, что получившаяся библиотека будет соответствовать [Linux System V ABI](https://gitlab.com/x86-psABIs/x86-64-ABI/-/jobs/artifacts/master/raw/x86-64-ABI/abi.pdf?job=build).

В частности, это позволяет ей быть использованной из кода на почти любом языке программирования через [FFI](https://en.wikipedia.org/wiki/Foreign_function_interface). Например, тесты к этому заданию написаны на языке Haskell и напрямую вызывают реализованные на ассемблере арифметические функции.

Также для вашего удобства в [app/main.cpp](app/main.cpp) вы найдёте простую программу на C++ для ручного запуска этих функций.

## Инструкция по работе

Для выполнения задания и запуска примеров вам понадобится любой дистрибутив Linux на 64-битной системе x86-64.
В том числе подойдёт Docker или WSL.

Модифицируйте файлы [add.asm](lib/math/add.asm), [sub.asm](lib/math/sub.asm) и [mul.asm](lib/math/mul.asm), чтобы они выполняли сложение, вычитание и умножение.

По аналогии с тем, как это делается в [io.asm](lib/io.asm), в своём решении вы можете пользоваться функциями из [common.asm](lib/common.asm), если посчитаете их полезными.

### Сборка

```bash
# Install required dependencies (Debian)
$ sudo apt install nasm binutils cmake build-essential

# Configure build directory
$ cmake -B build

# Build both lib and app
$ cmake --build build
```

### Запуск консольной утилиты на C++

```bash
$ ./build/app/long-int-app add
123     # first operand (input)
42      # second operand (input)
165     # result (output)
```

Также можно передать флаг `--check-abi` для проверки соответствия ABI:

```bash
$ ./build/app/long-int-app mul --check-abi
123
42
ABI violated:
  - R15 clobbered
```

## Примечания

1. На вход в `long_int_add`, `long_int_sub` и `long_int_mul` поступают беззнаковые числа указанной длины (в qwords).
2. Порядок qwords в представлении числа &mdash; little-endian.
3. Результат `long_int_add` или `long_int_sub` двух чисел длины `N` qwords &mdash; беззнаковое число длины `N` qwords (переполнение в соответствии с модульной арифметикой).
4. Результат `long_int_mul` двух чисел длины `N` qwords &mdash; беззнаковое число длины `2N` qwords.
5. Программу можно реализовать по-разному, но если ваше решение избыточно расходует память или иным образом неэффективно, вас попросят это исправить.
6. Оставляйте комментарии в коде, особенно если делаете что-то нетривиальное &mdash; это сильно упрощает проверку. Переусердствовать с ними однако не стоит, не нужно сопровождать комментарием каждую строчку в коде.
